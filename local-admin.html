💡 使用流程

1️⃣ 先点「📁 选择项目文件夹」，选到本项目所在文件夹（一般会自动关联）
2️⃣ 从左侧切换到「🗺️ 地图编辑 / 🐱 猫咪管理 / 🪢 关系管理 / 📖 故事集」，每个功能独立一页，编辑区更宽敞
3️⃣ 改完点「💾 保存到本地」；全部完成后到「🚀 部署到 GitHub」页填写仓库信息并推送
4️⃣ 编辑猫咪时，点「＋ 添加猫咪」或某只猫的「编辑」会打开加宽编辑窗，字段一目了然

📖 故事集

故事置顶

点击故事右侧「📌 置顶」把它固定到公开站故事集最前面（最多 3 篇）；未置顶的故事自动按日期（无日期按上传时间）从新到旧排列。改完点下方「💾 保存到本地」，公开站刷新即可预览。

置顶/编辑后记得点这里保存

💡 置顶的 3 篇可以用右侧 ▲▼ 调整先后；想换掉某篇，点「📌 置顶 N」取消后再置顶新的即可。

📚 猫咪小知识

这是公开站顶部「📚 猫咪小知识」栏目。点「＋ 添加小知识」或某篇的「编辑」即可修改，支持配图、关联猫咪；正文写不下可分段，公开站会自动折叠长文。

编辑 / 增删后记得点这里保存

🚀 部署到 GitHub

🔑 Token 怎么获取？
  1. 打开 github.com/settings/tokens/new?type=beta
  2. Repository access 选 Only select repositories → 勾选 campus-cats
  3. Permissions → Contents 设为 Read and write
  4. Generate 后复制 github_pat_... 到上面
