① 连接 GitHub（第一次要做，之后会自动记住）

🔑 不知道 Token 怎么弄？点这里看 3 步教程（只需做一次）
  1. 打开 github.com/settings/tokens/new?type=beta（GitHub 登录后）
  2. 名字随便填（如 campus-cats），在 Repository access 选 Only select repositories，勾选 campus-cats；在 Permissions 里把 Contents 设为 Read and write
  3. 点最下方 Generate token，把生成的 github_pat_… 复制粘贴到上面的 Token 框，点「保存设置」。Token 只存本浏览器，不会泄露。

② 在地图上添加 / 修改猫咪位置

点击「从 GitHub 拉取数据」后，在这里点地图空白处 = 在那个位置添加猫咪；拖动已有圆点 = 调整位置。点下方卡片上的「编辑」可改信息。

③ 猫咪列表（点「＋ 添加猫咪」或直接点地图）

请先拉取数据。

④ 关系（亲戚 / 朋友，可留空）

不是所有猫都有亲戚，按需添加：选「猫A」→ 关系 → 「猫B」→ 备注。

请先拉取数据。

⑤ 保存到 GitHub（提交后两个网站自动更新）

⚠️ 还没设置 Token 或还没拉取数据：请先完成 ①（填仓库/分支/Token → 保存设置 → 拉取数据）。
